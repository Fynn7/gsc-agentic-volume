# 04 前沿方法调研

> 检索日期 2026-10-25。来源是 arXiv、会议页面和出版商页面的摘要与正文片段，**没有逐篇精读全文**；标注“经典文献”的条目来自我的既有知识，本次没有重新检索。每条都说明“能借什么、不借什么”，避免把论文结论直接当成对本项目的保证。

## 1. 摘要

1. 近两年做“自然语言驱动体可视化”的工作，几乎都采用同一个套路：**先把体数据分解成可寻址的成分，再让 LLM 在成分层面行动**，而不是让模型直接去拧传输函数旋钮。本项目目前正好是后者。
2. 传输函数优化类工作普遍把**生成和评估拆开**（进化式探索器加 MLLM 评估器），并要求评估有可复现的信号。
3. 开放词汇分割（SAM 2、SAM 3）让“在切片上点一下或给一个名词短语，得到 3D 掩膜”成为可行的零样本工具。
4. 视觉工具使用的强化学习（DeepEyes 等）说明，小模型的视觉推理能通过带可验证奖励的训练明显提升；这条路成本高，但本项目的合成课程恰好能提供可验证奖励。
5. 代码作为接口（ParaView 脚本生成类工作）与本项目“只给旋钮”的接口形成对比。

## 3. 分割与 3D 理解

### 3.1 把切片当视频：SAM 2 与 SAM 3

- **SAM 2 零样本 CT 分割**（arXiv 2603.23116）：据摘要，它把冻结权重的 SAM 2 用在 CT 切片序列上，通过向相邻切片传播做出连贯的 3D 分割，不需要训练。
- **SAM 3**（arXiv 2511.16719；ICLR 2026）：提出可提示概念分割，概念提示可以是简短名词短语、图像示例或两者结合，对图像和短视频（约 30 秒以内）返回所有匹配实例的掩膜和身份；检测和定位用一个存在性头分离。
- 对本项目：在一张 x 切片上点一下块状物，用 SAM 2 向相邻切片传播得到 3D 掩膜（路径 D）；SAM 3 的文本提示在工业 CT 灰度图上是否有效属于**待验证**，它的训练分布是自然图像。
- 风险：CT 灰度切片与自然图像分布差异大；球壳这类单体素厚的结构对基于掩膜的传播不友好。

### 3.2 经典方法（经典文献，未在本次检索中复核）

- **梯度门控直方图**：材料内部梯度小，边界梯度大。只统计低梯度体素的直方图，峰会比全体直方图清晰得多（Levoy 1988；Kindlmann 与 Durkin 1998 的半自动传输函数生成；Kniss、Kindlmann、Hansen 2002 的多维传输函数）。这是 `analyze_structure` 的首选起点。
- **连通域标记、形态学开闭、距离变换**：用于从材料带得到离散物体，并用最大距离值区分“薄壳”和“实心体”。
- **多级 Otsu 阈值、分水岭、高斯混合**：当直方图峰不清晰时的后备划分方式。

## 5. 通用的智能体系统做法

以下是常见工程做法，来自一般经验，本次没有逐项检索；列出是因为实施计划用到了它们。

1. **候选枚举加选择题**：把开放式搜索改成“在 N 个带编号的候选里选一个”，类似 Set-of-Mark 的做法，能显著减少小模型的幻觉。
2. **验证器在回路里**：每次产出都由程序计算分数，失败则回退重选。
3. **结构化笔记代替自由文本摘要**：把已确认的事实（节点表、已选、已拒）存成结构化数据，每轮原样注入，避免“传话游戏”式的错误固化。
4. **一次工具调用批量产出多个视图**：把渲染成本摊薄，让“观察预算”按决策计，不按渲染计。
