4. Verwendetes Python-Hilfsskript
--------------------------------

Für die weiteren Aufrufe wurde mit einem Shell-Here-Document die Datei
/private/tmp/borg_call.py angelegt. Ihr damaliger Inhalt war:

import json,urllib.request,sys,base64
name=sys.argv[1]; args=json.loads(sys.argv[2]) if len(sys.argv)>2 else {}
r=urllib.request.Request('http://127.0.0.1:8765/mcp',data=json.dumps({'jsonrpc':'2.0','id':1,'method':'tools/call','params':{'name':name,'arguments':args}}).encode(),headers={'Content-Type':'application/json'})
d=json.load(urllib.request.urlopen(r,timeout=90))
for c in d.get('result',{}).get('content',[]):
 if c.get('type')=='image':
  path=sys.argv[3] if len(sys.argv)>3 else '/private/tmp/borg.png'
  open(path,'wb').write(base64.b64decode(c.pop('data')));c['saved']=path
if 'structuredContent' in d.get('result',{}): d['result'].pop('content',None)
print(json.dumps(d))

Die Aufrufe dieses Skripts wurden mit erweiterter Sandbox-Berechtigung für
den lokalen MCP-Zugriff ausgeführt. Das Skript verwendet nur Python-Standard-
bibliotheken. Es sendet tools/call-Anfragen als JSON-RPC und speichert von
capture_screenshot gelieferte PNG-Bildblöcke.

Wichtige Interpretation der Parameter:
- Clipping-Minimum und -Maximum sind normalisierte Volumengrenzen.
- rotation ist ein Quaternion; die beobachteten Werte entsprechen [x,y,z,w].
- set_transform verändert nur die jeweils angegebenen Komponenten.
- set_lighting normalisiert den angegebenen Richtungsvektor automatisch.
- Die verwendeten Isowerte sind normalisierte Werte zwischen 0 und 1.
